# GIF 工具箱（独立 Fork）

`astrbot_plugin_gif_toolbox` 是 AstrBot 的本地图片与动图处理插件。它可以处理普通图片、GIF、APNG、WebP 动图和视频片段，不需要把素材上传到第三方图片处理服务。

支持 AstrBot：`>=4.16,<5`。

> 本项目 Fork 自 [shskjw/astrbot_plugin_gifcaijian](https://github.com/shskjw/astrbot_plugin_gifcaijian)。
> 
> 插件标识、数据目录和更新记录均使用 `astrbot_plugin_gif_toolbox`，可以与上游插件同时安装，不会互相覆盖。

## 安装

1. 在 AstrBot 插件安装页安装仓库：<https://github.com/Whereis-Alice/astrbot_plugin_gif_toolbox>。
2. 手动安装时，将整个插件目录放到 `data/plugins/astrbot_plugin_gif_toolbox`。
3. 让 AstrBot 自动安装依赖；若需要手动安装，请在 **AstrBot 正在使用的 Python 环境**执行：

   ```powershell
   pip install -r data/plugins/astrbot_plugin_gif_toolbox/requirements.txt
   ```

4. 重载插件或重启 AstrBot。

依赖中的 `Pillow>=10.3.0` 不会要求降级 Pillow，兼容 AstrBot 4.26.6 使用的 Pillow 12.2.0。不要为了本插件手动降级 AstrBot 核心依赖。

## 30 秒开始

命令示例使用 `/` 作为前缀。请按机器人实际配置替换；如果 AstrBot 未启用命令前缀，直接发送命令文字即可。

最稳定的操作方式只有两步：

1. 先发送图片、动图或视频。
2. **回复这条素材消息**，发送处理命令。

例如：

```text
回复一张图片：/图片转gif 0.5s
回复一张动图：/加速 2
回复一张动图：/倒放
回复一张动图：/gif裁剪 1:1 左侧
回复一张动图：/gif截取 1-30帧
回复一段视频：/视频转gif 1s-4s fps 10 0.5
```

部分平台也支持把素材和命令放在同一条消息发送。第一次使用时，可直接发送 `/gif工具箱帮助` 查看图片速查表。

## 先看这个：素材与输出

| 你提供的素材 | 可以做什么 | 常见输出 |
| --- | --- | --- |
| 单张图片 | 转 GIF、反色、旋转、翻转、对称、线稿、做旧、网格切图、查看信息 | GIF、PNG、JPEG 或多张 PNG |
| GIF / APNG / WebP 动图 | 变速、倒放、整体裁剪、按帧截取、变换、做旧、分解、查看信息 | GIF 或多张 PNG |
| 多张图片 | 按顺序合成 GIF | GIF |
| 精灵图 | 按网格切帧后合成动画 | GIF、APNG 或 WebP |
| 视频 | 截取片段并转动画 | GIF、APNG 或 WebP |

图片可以来自当前消息、被回复消息或合并转发。多图合成会按照消息中的出现顺序取图。若素材下载失败，通常是原消息已经过期，重新发送原图或原视频再回复即可。

## 按需求选命令

### 制作动画

| 需求 | 指令 | 说明 |
| --- | --- | --- |
| 把单张图包装为 GIF | `/图片转gif [时长]` | 画面内容不会自动产生运动，只是生成 GIF 动画容器。别名：`/单图转gif`。 |
| 用精灵图制作动画 | `/合成1gif [行x列] [时长] [边距]` | 从左到右、从上到下切出网格并依次播放。`/合成2gif` 仅为旧名称兼容，行为相同。 |
| 多张图片合成 GIF | `/多图合成gif [时长]` | 每张图片成为一帧，按消息顺序播放。 |
| 视频片段转动画 | `/视频转gif [开始-结束] [fps N] [缩放]` | 例如 `/视频转gif 1s-4s fps 10 0.5`。 |

### 编辑动图

这些命令需要 GIF、APNG 或 WebP 动图；静态图片会被拒绝。

| 需求 | 指令 | 关键说明 |
| --- | --- | --- |
| 加快、放慢播放 | `/加速 [倍率]`、`/减速 [倍率]`、`/调速 [倍率]` | `/加速 2` 是约两倍速；`/调速 0.5` 是约半速。 |
| 倒序播放 | `/倒放` | 别名：`/gif倒放`、`/动图倒放`。帧顺序和每帧时长会一起倒序，输出 GIF。 |
| 裁掉画面范围 | `/gif裁剪 ...` | 输出仍是一张动图，所有帧使用同一个裁剪框。别名：`/动图裁剪`。 |
| 删除前后帧或保留帧段 | `/gif截取 ...` | 时间轴裁剪，不改变画面范围。别名：`/动图截取`。 |
| 查看帧数等信息 | `/gif信息` | 静态图片也可查询。别名：`/动图信息`、`/gif详情`。 |
| 拆成 PNG 帧 | `/gif分解` | 使用合并转发发送多张 PNG。 |

### 处理单张图或普通图片

| 指令 | 效果 |
| --- | --- |
| `/反色` | 反转颜色，保留透明度。 |
| `/顺时针`、`/逆时针` | 旋转 90 度。 |
| `/左右翻转`、`/上下翻转` | 水平或垂直翻转。 |
| `/左对称`、`/右对称`、`/上对称`、`/下对称` | 保留对应一半，再镜像补齐另一半。 |
| `/图片转线稿` | 本地边缘检测；动图只取第一帧。 |
| `/表情包做旧 [次数]` | 模拟反复压缩转发，次数默认为 5，范围为 1 到 50；也兼容 `/做旧 [次数]`。 |
| `/裁剪 [行x列] [边距]` | 网格切图，输出多张 PNG 的合并转发。 |

基础变换和做旧可以处理静态图片与动图：静态图通常输出 PNG 或 JPEG，动图输出 GIF。

## 通用参数写法

### 时长：用于图片转 GIF、精灵图和多图合成

| 正确写法 | 含义 |
| --- | --- |
| `0.5s`、`0.5秒`、`0.5` | 每帧停留 0.5 秒。 |
| `5fps` | 每秒 5 帧，即每帧约 0.2 秒。 |
| `1s` | 每帧停留 1 秒。 |

`500ms` 和整数 `500` **不会**被识别为时长，请写成 `0.5s`。帧时长会限制在 20ms 到 60000ms。

> 图片与合成命令使用 `5fps`；视频命令使用 `fps 5`。两种写法不同。

### 网格与边距

`行x列` 可写成 `2x3`、`2*3` 或 `2×3`。

边距单位是像素：

```text
边距 8                       # 四边各裁掉 8 像素
左边距 16 右边距 16           # 只裁左右
边距 8 上边距 4               # 先设四边 8，再把上边改成 4
```

## 复杂命令详解

### 动图变速

```text
/加速 [倍率]
/减速 [倍率]
/调速 [倍率]
```

倍率省略时为 `2`，可用范围是 `0.1` 到 `20`。`/减速` 请填写大于 1 的值；例如 `/减速 2` 才表示减为约半速。

| 指令 | 示例 | 实际含义 |
| --- | --- | --- |
| `/加速 N` | `/加速 2` | 按原速度的 N 倍播放。 |
| `/减速 N` | `/减速 2` | 每帧时长乘以 N，约为原来的一半速度。 |
| `/调速 N` | `/调速 0.5` | 指定目标倍率，小于 1 时变慢。 |

GIF 在常见客户端中通常不能稳定显示低于 20ms 的帧间隔。因此，倍速很高时，保留全部帧的结果可能无法继续变快。将配置 `gif_speed_allow_frame_drop` 设为 `true` 后，插件可均匀丢帧以更接近目标倍速，但会减少中间画面。

兼容写法：`变快`、`变慢` 也可触发变速处理。

### 动图倒放

`/倒放` 会在完整画面合成后，把已处理的帧和对应时长一起倒序，再统一编码为 GIF。输入动图的有限循环次数不会保留，输出会循环播放。源帧时长低于 20ms 时会按 20ms 处理；帧数超过 `max_frames` 时，会均匀采样后再倒放。

### 动图整体裁剪：`/gif裁剪`

`/gif裁剪` 是裁掉每一帧的画面范围，最后仍输出**一张动图**。它与下文的 `/裁剪` 网格切图不是同一功能。

```text
/gif裁剪 [比例] [位置]
/gif裁剪 尺寸 宽x高 [位置]
/gif裁剪 边距 N [上/下/左/右边距 N ...]
```

| 模式 | 示例 | 结果 |
| --- | --- | --- |
| 按比例裁剪 | `/gif裁剪 1:1` | 从原画面取符合比例的最大区域，不缩放内容。 |
| 按尺寸裁剪 | `/gif裁剪 尺寸 720x720 左下` | 裁出指定像素尺寸，不缩放内容。 |
| 按边距裁剪 | `/gif裁剪 边距 24 上边距 8` | 从边缘裁掉指定像素范围。 |

比例和尺寸模式可在末尾指定位置：`左上`、`上`、`右上`、`左`、`居中`、`右`、`左下`、`下`、`右下`；省略时为 `居中`。边距模式不能附带位置。

### 按帧截取：`/gif截取`

`/gif截取` 处理的是时间轴上的帧，不会裁掉画面范围。

| 写法 | 结果 |
| --- | --- |
| `/gif截取 前10帧` | **删除**前 10 帧，保留后面的帧。 |
| `/gif截取 后10帧` | **删除**后 10 帧，保留前面的帧。 |
| `/gif截取 前8帧 后8帧` | 同时删除前 8 帧和后 8 帧。 |
| `/gif截取 10-60帧` | 只保留第 10 到第 60 帧，帧号从 1 开始，首尾都包含。 |

至少要保留 2 帧；删除数量和帧号范围均为 1 到 1000000。范围写法也支持 `第10到第60帧`、`10~60帧` 和 `10至60帧`。超长动图会先确定保留范围，再在该范围内按 `max_frames` 均匀采样。

### 精灵图合成：`/合成1gif`

```text
/合成1gif [行x列] [时长] [边距]
```

默认是 `6x6`、每帧 `100ms`、无边距。行和列分别为 1 到 30；网格总帧数超过 `max_frames` 时会均匀采样。

```text
/合成1gif
/合成1gif 4x6 0.12s
/合成1gif 6x6 10fps 边距 8 上边距 4
```

输出格式取决于 `output_format` 配置，可选 GIF、APNG 或 WEBP。

### 多图合成：`/多图合成gif`

```text
/多图合成gif [时长]
```

从当前消息、回复消息或合并转发中按顺序读取多张图片，每张图片成为一帧。默认每帧 `500ms`，默认最多读取 `20` 张图片，由 `max_multi_images` 控制。动图素材只会使用第一帧；尺寸不同的图片会居中到同一透明画布上。

```text
/多图合成gif
/多图合成gif 0.25s
/多图合成gif 5fps
```

### 网格切图：`/裁剪`

```text
/裁剪 [行x列] [边距]
```

这不是 `/gif裁剪`：它会把一张图片切成多张 PNG，并通过合并转发发送。默认 `1x1`，行列均为 1 到 20；分块数不能超过 `max_forward_parts`。

```text
/裁剪 2x3
/裁剪 3x3 边距 12
/裁剪 2x4 左边距 16 右边距 16
```

### 视频转动画

```text
/视频转gif [开始时间-结束时间] [fps N] [缩放比例]
```

| 参数 | 示例 | 说明 |
| --- | --- | --- |
| 时间范围 | `1s-4s`、`1.5秒~4秒`、`1-4` | 不写时从 0 秒处理到视频结尾，但仍受最大时长限制。 |
| 帧率 | `fps 10` | 范围 1 到 60；原视频帧率更低时会使用较低值。 |
| 缩放 | `0.5` | 范围 0.1 到 1.0，`0.5` 表示宽高缩小到 50%。 |

```text
/视频转gif
/视频转gif 1s-4s
/视频转gif 1s-4s fps 10 0.5
/视频转gif 0-8秒 fps 15 1
```

视频转换需要 AstrBot 的 Python 环境能够使用 `imageio[ffmpeg]`；其他图片和 GIF 功能不依赖 FFmpeg。

### 动图信息与分解

```text
/gif信息
/gif分解
```

`/gif信息` 可以查询静态图片或动图，显示格式、尺寸、文件大小、动画状态、原始帧数、循环次数、帧时长和可用元数据。`/gif分解` 只接受动图，会将帧拆为 PNG 并以合并转发发送；实际发送的帧数受 `max_frames` 限制。

## 内置图片速查

```text
/gif工具箱帮助
/gif速查
/动图速查
```

返回一张可点开查看的命令速查图片，适合在聊天中快速查语法。复杂参数、范围和配置说明以本 README 为准。

## 配置与处理限制

在 AstrBot 插件配置面板可调整下列项目。较大的尺寸、帧数和输出体积会明显增加处理时间，也可能触发聊天平台的发送限制。

### 输入与处理规模

| 配置项 | 默认值 | 作用 |
| --- | ---: | --- |
| `max_input_size_mb` | 30 MB | 单个输入文件的最大体积，可设 1 到 200 MB。 |
| `download_timeout_seconds` | 60 秒 | 远程图片或视频下载超时，可设 5 到 300 秒。 |
| `max_image_side` | 1280 px | 处理时图片最长边上限，可设 64 到 4096。 |
| `max_frames` | 160 | 单次动画最多处理帧数，可设 2 到 500。逐帧动图处理超出时通常均匀采样；多图合成和视频转动画则优先保留最先读到的帧。 |
| `max_output_size_mb` | 10 MB | 动画输出目标体积；超出时会尝试缩小和减色。 |
| `gif_max_colors` | 256 | GIF 最大颜色数，可设 2 到 256；降低可减小体积。 |

### 生成默认值

| 配置项 | 默认值 | 作用 |
| --- | ---: | --- |
| `output_format` | `GIF` | 精灵图合成和视频转动画的输出格式：GIF、APNG 或 WEBP。 |
| `single_image_gif_duration_ms` | 500ms | 单图转 GIF 的默认每帧时长，可设 20 到 60000ms。 |
| `single_image_gif_frame_count` | 2 | 单图转 GIF 的重复帧数，可设 2 到 12。 |
| `max_multi_images` | 20 | 多图合成一次最多读取的图片数，可设 1 到 60。 |
| `max_forward_parts` | 40 | 网格裁剪或分解时最多发送的图片数，可设 1 到 100。 |
| `max_gif_duration` | 10 秒 | 视频单次最长处理片段，可设 0.5 到 120 秒。 |
| `default_fps` | 10 | 视频转动画的默认帧率，可设 1 到 60。 |
| `default_scale` | 0.3 | 视频转动画默认缩放比例，可设 0.1 到 1.0。 |

### 可选兼容行为

| 配置项 | 默认值 | 作用 |
| --- | --- | --- |
| `gif_speed_allow_frame_drop` | `false` | 开启后允许调速均匀丢帧，以突破 GIF 20ms 帧间隔造成的速度上限。 |
| `enable_at_avatar` | `true` | 基础图片变换在没有附图时，允许使用被 @ 的 QQ 用户头像；仅适用于兼容的 OneBot/QQ 平台。 |

## 常见问题

### 为什么 `/加速 30` 看起来和 `/加速 4` 差不多？

GIF 在常见客户端中存在约 20ms 的最小帧间隔。保留全部帧时，到达这个下限后无法继续缩短帧时长。开启 `gif_speed_allow_frame_drop` 后可以丢帧获得更高速度，但画面会更跳。

### 为什么日志里有发送超时，图片过一会儿却成功发出来？

这通常是 QQ/NapCat 的消息发送确认超时：AstrBot 等待确认时超过了适配器时限，但客户端随后仍完成了消息投递。大文件、多帧动图更容易出现这种情况；若图片最终发出，处理结果本身没有丢失。

### 为什么视频转动画失败？

先确认回复的是视频消息，并确认 AstrBot 所在 Python 环境能够使用 `imageio[ffmpeg]`。视频过大、来源过期、片段太长或平台不提供可读文件路径，也会导致失败。

### 为什么动图功能提示素材不支持？

`/加速`、`/倒放`、`/gif裁剪`、`/gif截取` 和 `/gif分解` 都要求真正的 GIF、APNG 或 WebP 动图。静态图片请使用图片变换、`/图片转gif` 或 `/gif信息`。
